# Сетевая демо-аркада

Одна комната на четырёх участников, включая ведущую: Документы → один вопрос → Серёга-босс. У каждого свой герой, ответ и здоровье; задача и босс общие. Играть нужно на компьютере с клавиатурой.

## Репетиция

1. Ведущая открывает `/arcade?host=1`, выбирает ник и входит с существующим паролем админки «Чепухи».
2. Задаёт отдельный пароль участников (минимум шесть символов) и открывает комнату.
3. Трое участников открывают `/arcade`, вводят свои ники и пароль комнаты. Присоединяться можно в лобби до начала уровня.
4. Когда все появились в списке, ведущая нажимает «Начать уровень».
5. Любой игрок по платформам добирается до «Заголовок», нажимает E, затем до «Сохранить» и снова нажимает E. Кнопки также доступны мышью, когда герой рядом.
6. Ведущая переводит команду к вопросу. Каждый выбирает ответ, стоя на площадке. Ведущая раскрывает правильный ответ и начинает бой.
7. Все стреляют в босса, удерживая F, и перепрыгивают его снаряды. После смерти герой лежит с глазами-крестиками; бой продолжается, пока жив хотя бы один подключённый игрок.
8. После репетиции ведущая нажимает «Закрыть комнату». Игроки отключаются, закрытие сохраняется на сервере.

Пароль участников можно изменить в лобби: существующие гостевые входы аннулируются, участники входят заново. Новые участники не допускаются без подключённой ведущей. При потере связи ведущей игра встаёт на паузу; после возвращения она нажимает «Продолжить».

Перезагрузка страницы восстанавливает вход и героя. Отключённое место сохраняется 45 секунд. Комната не завершается из-за перехода в другую вкладку: остановится только герой этого игрока.

Управление: A/D или ←/→ — идти; Space/W/↑ — прыгать; E — действие; F — стрелять; Esc — пауза для ведущей. Клик по полю возвращает фокус управления.

Босс начинает с 48 HP на участника. Доля правильных ответов уменьшает здоровье до 30%; каждая новая попытка дополнительно уменьшает его на 25%, до минимума 10 HP на участника. У игроков по 3 HP. Пульт позволяет ставить паузу, пропускать этап, повторять бой и начинать сценарий заново.

## Инфраструктура и выпуск

Next.js на Vercel отдаёт интерфейс и API входа. PartyKit-проект `chepuha-rooms` содержит отдельный обработчик `arcade` и комнату `demo`: `/parties/arcade/demo`. Он рассчитывает игру и рассылает состояние 20 раз в секунду. Настройки комнаты и состояние сохраняются в отдельном storage этой комнаты. Прежний обработчик `main` сохранён; production-комнаты «Чепухи» используют Neon API. Новый домен PartyKit создать не удалось из-за общего лимита сервиса, поэтому аркада опубликована на существующем домене.

Vercel и PartyKit используют общий серверный `ARCADE_SECRET`; Vercel также требует `NEXT_PUBLIC_ARCADE_HOST` и существующий `ADMIN_PASSWORD`. Секрет не передаётся в клиент. Билеты входа подписаны, действуют 12 часов и отзываются при закрытии/смене пароля.

`node scripts/release-arcade.mjs` публикует отдельный production deployment Vercel через `--skip-domain`, без переключения `chepuha.fun`. Отдельный `vercel.arcade.json` выбирает Webpack для этого выпуска: установленный Turbopack ошибается при обработке Google Fonts. Скрипт конфигурирует секрет через stdin, ждёт READY и проходит реальный сетевой сценарий четырьмя тестовыми подключениями. После проверки комната закрыта.

## Локальная разработка и проверка

Без `NEXT_PUBLIC_ARCADE_HOST` development-маршрут `/arcade` показывает прежний одиночный прототип. Его также можно открыть по `/arcade/local` в development. Эти локальные маршруты не заменяют сетевую репетицию.

```bash
npm run dev:next -- --hostname 127.0.0.1 --port 3010
./node_modules/.bin/tsx scripts/check-arcade-engine.ts
./node_modules/.bin/tsx scripts/check-arcade-room.ts
./node_modules/.bin/tsx scripts/check-arcade-server.ts
node scripts/check-arcade-e2e.mjs
npm run lint
./node_modules/.bin/tsc --noEmit
ARCADE_TEST_BUILD_DIR=.next-arcade-test npm run build -- --webpack
```

E2E самостоятельно запускает изолированные Next.js/PartyKit с временными секретами, проверяет четыре WebSocket-клиента, затем закрывает комнату и останавливает процессы. Остальные уровни и финальный квиз пока не входят в демо.
